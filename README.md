# 📈 Predictive Analytics Using Historical Data

## 📌 Project Overview

This project focuses on predicting future sales trends using historical sales data from the Superstore dataset. The data was cleaned, preprocessed, and analyzed before training a Linear Regression model to forecast sales. The project also includes data visualizations and model evaluation to measure prediction performance.

---

## 🎯 Objectives

- Clean and preprocess historical sales data.
- Analyze monthly sales trends.
- Build a predictive model using Linear Regression.
- Evaluate model performance.
- Visualize actual and predicted sales.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## 📂 Dataset

- **Dataset:** Superstore Sales Dataset
- **Format:** CSV

---

## 🚀 Features

- Data cleaning and preprocessing
- Removal of missing values and duplicates
- Monthly sales trend analysis
- Linear Regression model for sales prediction
- Model evaluation using MAE and R² Score
- Visualization of actual vs predicted sales
- Exportable prediction results

---

## 📊 Project Workflow

1. Load the dataset
2. Explore the data
3. Clean missing values and duplicates
4. Convert date columns
5. Aggregate monthly sales
6. Train a Linear Regression model
7. Predict future sales
8. Evaluate model accuracy
9. Visualize the results

---

## 📈 Output

The project generates:

- Monthly Sales Trend graph
- Actual vs Predicted Sales graph
- Model evaluation metrics (MAE and R² Score)

# Predictive Analytics Using Historical Data

## Overview
This project predicts future sales trends using historical data from the Superstore dataset. It includes data preprocessing, Linear Regression modeling, evaluation, and visualization.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Data Cleaning
- Monthly Sales Analysis
- Linear Regression Model
- Model Evaluation
- Prediction Visualization
